## Abstract

The proposed project, **LLM-Based Intelligent Personal Finance Advisor**, aims to provide personalized financial guidance by combining Machine Learning and Large Language Models (LLMs). The system analyzes users' income and expenditure patterns to understand their financial behavior and predicts their monthly savings using Machine Learning models. It also identifies unnecessary expenses, provides personalized budgeting suggestions, generates a Financial Health Score, and offers personalized financial guidance through an LLM. The system is designed to help users improve their financial planning, budgeting, savings, and overall financial well-being through intelligent and data-driven recommendations.

## Objectives

- To analyze users' income and expenditure patterns to understand their financial behavior.
- To predict users' monthly savings using Machine Learning models.
- To identify unnecessary expenses and provide personalized budgeting suggestions.
- To generate a Financial Health Score based on the user's financial condition.
- To recommend suitable investment opportunities based on the user's available savings and risk profile.
- To provide personalized financial guidance using an LLM.
- To improve users' financial planning, budgeting, and overall financial well-being through intelligent recommendations.

## Key Features

- Income and expenditure analysis
- Machine Learning-based monthly savings prediction
- Unnecessary expense identification
- Personalized budget planning
- Financial Health Score
- LLM-based personalized financial guidance
- Investment recommendations based on financial profile
- Data-driven financial planning
